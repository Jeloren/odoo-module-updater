# 0.3.0

- Добавлен RPC-режим обновления через работающий Odoo 17 без остановки процесса.
- Добавлены SecretStorage, сессии по подключению и базе, явная обработка неопределённого исхода.
- Добавлен режим вёрстки: XML из manifest data, задержка 800 мс, последовательная очередь и остановка после ошибки.
- Добавлены автоматические проверки RPC, конфигурации и очереди сохранений.
- Старые профили по умолчанию продолжают использовать CLI.
