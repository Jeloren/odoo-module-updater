# Демонстрация на пять минут

Тема: «Ускорение разработки интерфейсов Odoo 17 средствами Visual Studio Code».

1. Odoo и повторяющаяся проверка изменений интерфейса — 30 секунд.
2. Ручной цикл: XML, сохранение, обновление модуля, проверка результата — 40 секунд.
3. Расширение: выбранная цель, CLI/RPC, очередь сохранений — 45 секунд.
4. Учебная форма до и после обновления — 60 секунд.
5. Измерения на локальном стенде — 45 секунд.
6. Результат и ограничения — 40 секунд.

## Живая демонстрация

Используйте отдельную базу Odoo 17 и небольшой модуль с XML-формой и QWeb-шаблоном в `data` manifest.
Выберите RPC-профиль и базу, откройте XML, включите режим вёрстки. Измените подпись группы или вкладки и сохраните файл.
После сообщения об успехе обновите браузер. Убедитесь, что PID серверного процесса не изменился.
При ошибке XML режим выключается. Исправьте файл и явно включите режим заново.

Нативный VS Code должен видеть исходники по тому же пути, по которому их использует Odoo. Не показывайте настройки с реквизитами на проекторе.

## Как корректно сравнивать

На подготовленном учебном стенде выполнены пять чередующихся повторов каждого способа.
Медиана от сохранения до получения обновлённого HTML: штатный веб-метод Odoo — 3,43 с; CLI с перезапуском — 12,80 с;
RPC расширения — 6,08 с; режим вёрстки — 6,24 с. Это автоматизированные интеграционные замеры, без ручной навигации и браузерной отрисовки.
В тесте интерфейс VS Code заменён адаптером, а код расширения, Odoo и PostgreSQL реальные. Веб-базовая линия вызывает тот же endpoint, что кнопка Odoo, с уже выбранным модулем.
Два режима расширения сравниваются на одной версии кода. Числа не относятся к произвольному проекту или скорости всей разработки.

Преимущество перед интерфейсом Odoo — меньше ручных действий. Преимущество RPC перед CLI на этом стенде — отсутствие остановки и запуска процесса.
Для части XML штатный `--dev=xml` позволяет не обновлять модуль вовсе; это также проверено и должно быть отражено в выводах.

Не обещайте hot reload Python, нулевой простой, безошибочную работу на любых базах или гарантированный автоматический откат.
