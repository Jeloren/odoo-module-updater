# Демонстрация на конференции

Рабочее название выступления — «Расширение VS Code как инструмент автоматизации разработки Odoo».

## Сценарий на 7–10 минут

1. Покажите повторяющуюся задачу разработчика — открыть терминал, выбрать базу, вспомнить имя модуля,
   остановить сервер, запустить обновление, вернуть сервер в работу.
2. Объясните, что можно автоматизировать средствами VS Code. Покажите `package.json`, регистрацию команды,
   `createStatusBarItem`, `showQuickPick` и `workspaceState`.
3. Откройте `.vscode/odoo-update.json`. Покажите, как JSON Schema подсказывает поля для Docker и local.
4. Загрузите каталог аддонов. Найдите свой модуль по названию и покажите реальный путь и состояние установки.
5. Выберите модуль с двумя уровнями зависимых модулей. Откройте план, затем запустите обновление на отдельной демо-базе.
6. Перезагрузите окно VS Code и покажите сохранённый выбор. Следующее обновление запускается той же кнопкой.
7. Покажите автоматические тесты восстановления сервера после ошибки и структуру Release с VSIX и исходниками.

## Что объяснить на коде

- Интерфейс VS Code описан командами и Tree View, реализованными через API редактора.
- Конфигурация проекта отделяет команды расширения от путей конкретной установки.
- Список модулей берётся из окружения Odoo, поэтому Docker-пути обрабатываются внутри контейнера.
- `ast.literal_eval` читает manifest как данные. Каталог работает с БД через read-only соединение.
- План показывает последствия операции. Выполнение делегируется штатному Odoo `-u`.
- `finally` возвращает запущенный сервер в работу при ошибке. Тест проверяет именно этот сценарий.
- VSIX — устанавливаемый ZIP-пакет с манифестом и кодом. Marketplace является одним из способов распространения.

## Подготовка демонстрации

Создайте отдельную демо-базу и три маленьких модуля с цепочкой зависимостей. Проверьте их установку и обновление заранее.
Подготовьте скриншоты плана и журнала успешного запуска на случай отсутствия Docker или сети на площадке.
Не показывайте реальный `odoo.conf` с реквизитами подключения на проекторе.

Для слайдов пригодятся измеренные вами время ручного обновления и время запуска кнопкой,
а также число действий, которое вы выполняете в каждом сценарии. После выступления слушатель сможет установить VSIX
и настроить тот же инструмент для своего проекта.
